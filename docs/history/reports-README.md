# Report locali e risultati misurati

Cartella di report per l'agente. `F0_environment_local.txt` viene prodotto dall'eventuale script read-only `tools/Collect-Environment.ps1`. **Non** interpretare l'assenza di questo file come configurazione verificata.

Modello risultato test:
- Data/OS/versioni driver
- Procedura esatta
- Fatti osservati, error codes e log
- PASS/FAIL
- Ripristino, impatti su REAPER/Console

Non inserire tracce audio, nomi di clienti o credenziali nei report condivisi.
